# Admin panel wording

Plain, professional copy across the admin panel (`/admin/dashboard`) and
MemberHub (`/member/dashboard`). Loading states say what is loading, empty states
say what is missing, buttons say what they do.

## Terms
| Use | Instead of |
|-----|------------|
| Team member | staff, staff member, operative |
| Registered member | user (in the Management list) |
| Role (Admin, Editor, Support, Superadmin) | access level |
| Designation | title, position |
| Role description | bio, bio / role description |
| Director | board member (the checkbox reads "Board director") |
| Loading projects… | Compiling entries…, Fetching records from the mainframe… |
| No records found. | No records found in this sector. |
| Saving… | Synchronizing… |
| Delete / Delete project | Purge, Delete Permanently (as a tooltip) |
| Submit Blog Post | Initiate Blog Publication |

## Rules
- No themed or sci-fi phrasing in loading, empty and error states.
- Sentence case for messages; Title Case only for headings and buttons.
- Loading messages end with an ellipsis and name the thing: "Loading programs…".
- Empty states say what is missing and, if useful, how to add it.
- Tooltips describe the action ("Feature on website"), not the mechanism
  ("Toggle Featured").

## Management screen
Opens on **Team Members** (grouped by role); **Registered Members** is the second tab.
